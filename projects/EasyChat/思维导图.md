# EasyChat

## 核心功能

### 账号认证与双 Token 机制 %%green%%
- 登录 / 注册 / 忘记密码 / QQ SMTP 邮箱验证码 %%green%%
- Access Token（30 分钟）+ Refresh Token（7 天）轮换刷新 %%green%%
- 主动登出黑名单 `token:blacklist` 与改密全量吊销 `token:revoke-before` %%green%%
- 前端 `request.ts` 401 并发单飞刷新与重放 %%green%%

### 好友与社交关系 %%green%%
- 昵称 / 邮箱关键字用户搜索 %%green%%
- 加好友验证开关（`user_settings.friend_verify`） %%green%%
- 好友申请发送、同意/拒绝审批与好友列表管理 %%green%%
- 删好友双向移除会话（Dubbo RPC + `CONVERSATION_REMOVED`） %%green%%

### 实时聊天与群聊系统 %%green%%
- 单聊（字典序拼接会话 ID）与群聊管理（群公告、头像、管理员、踢人、退群） %%green%%
- 群邀请卡片（`type=3` / `contentType=4`）与入群审批工单 %%green%%
- 客户端 `client_msg_id` 唯一索引发信幂等防重 %%green%%
- 2 分钟内限时撤回（`MESSAGE_UPDATE` 广播） %%green%%
- 单方面清空记录（`conversation_member.cleared_at`）与已读计数 %%green%%
- 腾讯云 COS 头像与聊天文件上传（上限 20MB） %%green%%

### Netty 长连接与多实例推送 %%green%%
- 30 秒一次性 `ws:ticket` 握手与 25 秒 `PING`/`PONG` 心跳 %%green%%
- Redis `ws:online` 在线状态维护与 Lua CAS 断开清理 %%green%%
- `local` / `kafka` 双模式投递与在线状态变更广播 %%green%%

### 桌面端与本地离线体验 %%green%%
- IndexedDB（`easychat-msg-{userId}`）按会话缓存历史消息 %%green%%
- Electron 登录小窗（400×720）与主界面（1280×840）导航联动切换 %%green%%
- 无边框自定义标题栏、快捷键、右键菜单与外链拦截 %%green%%

## 模块划分

- `easychat-common`（公共模块） %%green%%
    - `common-core`：通用返回 `Result`、异常处理、JWT/Email/COS 工具、DTO 与 MyBatis-Plus 分页
    - `common-security`：`JwtAuthFilter`、`TokenBlacklistService`、`@RateLimit` 切面、`TraceIdFilter`、`TraceIdDubboFilter`、`SentinelWebMvcConfig`
    - `common-mq`：`KafkaWsPushPublisher` 与自动装配属性 `EasychatKafkaProperties`
    - `common-api`：`UserQueryService`、`FriendRequestService`、`ConversationDeleteService` 及 `DubboFallbacks`
- `easychat-gateway`（网关 `:8080`） %%green%%
    - `GatewayAuthFilter`（JWT 黑名单 / WS Ticket 校验 / 路径规范化安全检查）
    - `WsLoadBalancerGatewayFilterFactory`（读取 Nacos `ws-port` 动态路由 Netty）
    - Sentinel 网关流控 + Swagger API 文档聚合（`/v3/api-docs/user|chat`）
- `easychat-user`（用户服务 `:8081` / Dubbo `:20880`） %%green%%
    - `AuthController`、`UserController`、`FriendController`、`UserQueryServiceImpl`
    - Flyway `V1__baseline.sql` + Sentinel 接口限流 + Actuator
- `easychat-chat`（聊天服务 HTTP `:8082` / Netty WS `:8083` / Dubbo `:20881`） %%green%%
    - `MessageController`、`GroupController`、Netty `NettyServer`/`AuthWsHandler`/`ChatWsHandler`
    - `KafkaWsPushRouter`、`WsPushKafkaConsumer`、`WsSessionRegistry`、`WsOnlineStatusBroadcaster`
    - `FriendRequestServiceImpl`、`ConversationDeleteServiceImpl`、Flyway `V1~V6`
- `frontend/easychat`（前端与桌面端） %%green%%
    - Vue 3 Views / Components / Pinia Stores / IndexedDB `messageDb.ts`
    - Electron 主进程 `electron/main.ts`、`preload.ts`、`windowMode.ts`
