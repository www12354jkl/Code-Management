# 数据库设计

关联文档：[[../README|项目 README]] ｜ [[架构说明]] ｜ [[Redis与Kafka设计]] ｜ [[html/easychat-erd.html|EasyChat 数据库 E-R 图]]

## 一、库级约定与迁移机制

- 交互式 E-R 图：[[html/easychat-erd.html|EasyChat 数据库 E-R 图]]
- 数据库拆分：采用按业务域物理分库，初始化脚本位于 `deploy/mysql/init/01-databases.sql`：
  - `easychat_user`（MySQL `8.4`，`utf8mb4` / `utf8mb4_unicode_ci`）
  - `easychat_chat`（MySQL `8.4`，`utf8mb4` / `utf8mb4_unicode_ci`）
- 模式迁移：两个业务服务均集成 **Flyway**（`baseline-on-migrate: true`），启动时自动执行 `classpath:db/migration` 脚本：
  - `easychat-user`：`V1__baseline.sql`
  - `easychat-chat`：`V1__baseline.sql`、`V2__conversation_member_cleared_at.sql`、`V3__performance_indexes.sql`、`V4__message_recall.sql`、`V5__message_status_column.sql`、`V6__message_client_msg_id.sql`
- 关联模式：不依赖数据库物理外键约束，跨表与跨库关联由应用层服务与 Dubbo RPC（`UserQueryService` / `ConversationDeleteService`）维护。
- ORM 映射：MyBatis-Plus `3.5.16`，开启 `map-underscore-to-camel-case: true`。

## 二、`easychat_user` 库表结构

### 1. 用户基础表 `user`

| 字段 | 类型 | 约束 / 默认值 | 说明 |
|---|---|---|---|
| `id` | `VARCHAR(36)` | `PK` | 用户唯一 ID |
| `email` | `VARCHAR(128)` | `NOT NULL`, `UNIQUE uk_user_email` | 登录邮箱 |
| `password` | `VARCHAR(128)` | `NOT NULL` | BCrypt 加密密码 |
| `nickname` | `VARCHAR(64)` | `NOT NULL` | 用户昵称 |
| `avatar` | `VARCHAR(512)` | `NULL` | 头像 URL |
| `gender` | `TINYINT` | `DEFAULT 0` | 性别：`0` 保密、`1` 男、`2` 女 |
| `region` | `VARCHAR(64)` | `NULL` | 地区名称 |
| `region_code` | `VARCHAR(12)` | `NULL` | 地区编码 |
| `signature` | `VARCHAR(256)` | `NULL` | 个性签名 |
| `created_at` | `DATETIME` | `NOT NULL` | 创建时间 |
| `updated_at` | `DATETIME` | `NOT NULL` | 更新时间 |

### 2. 用户隐私与验证设置表 `user_settings`

| 字段 | 类型 | 约束 / 默认值 | 说明 |
|---|---|---|---|
| `id` | `BIGINT` | `PK`, `AUTO_INCREMENT` | 自增主键 |
| `user_id` | `VARCHAR(36)` | `NOT NULL`, `UNIQUE uk_user_settings_user` | 对应 `user.id` |
| `friend_verify` | `TINYINT` | `NOT NULL DEFAULT 1` | 加好友校验：`1` 需验证、`0` 允许任何人 |
| `created_at` | `DATETIME` | `NOT NULL` | 创建时间 |
| `updated_at` | `DATETIME` | `NOT NULL` | 更新时间 |

### 3. 好友关系表 `friend` & 好友申请表 `friend_request`

- **`friend`**：`id` (`VARCHAR(36)` PK)、`user_id`、`friend_id`、`created_at`；索引包含 `UNIQUE uk_friend_pair (user_id, friend_id)` 与 `KEY idx_friend_user (user_id)`，存储双向好友关系。
- **`friend_request`**：`id` (`VARCHAR(36)` PK)、`from_user_id`、`to_user_id`、`message` (`VARCHAR(256)`)、`status` (`TINYINT DEFAULT 0`：`0` 待处理、`1` 同意、`2` 拒绝)、`created_at`、`updated_at`；索引为 `KEY idx_friend_request_to_status (to_user_id, status)`。

## 三、`easychat_chat` 库表结构

### 1. 会话主表 `conversation`

| 字段 | 类型 | 约束 / 默认值 | 说明 |
|---|---|---|---|
| `id` | `VARCHAR(36)` | `PK` | 会话 ID（单聊按字典序生成 `uidA_uidB`，群聊为 UUID） |
| `type` | `TINYINT` | `NOT NULL` | 会话类型：`1` 单聊、`2` 群聊、`3` 群邀请会话 |
| `name` | `VARCHAR(128)` | `NULL` | 群名称或冗余会话名 |
| `avatar` | `VARCHAR(512)` | `NULL` | 群头像 URL |
| `owner_id` | `VARCHAR(36)` | `NULL`, `KEY idx_conversation_owner` | 群主 `user.id` |
| `announcement` | `VARCHAR(1024)` | `NULL` | 群公告 |
| `join_verify` | `TINYINT` | `DEFAULT 0` | 入群审批开关：`0` 直接加入、`1` 需管理员同意 |
| `status` | `TINYINT` | `NOT NULL DEFAULT 1` | 状态：`1` 正常、`0` 已解散 |
| `last_message` | `VARCHAR(512)` | `NULL` | 最新一条消息摘要 |
| `last_message_at` | `DATETIME` | `NULL` | 最新消息时间（用于列表排序） |
| `created_at` / `updated_at` | `DATETIME` | `NOT NULL` | 创建与更新时间 |

### 2. 会话成员表 `conversation_member`

| 字段 | 类型 | 约束 / 默认值 | 说明 |
|---|---|---|---|
| `id` | `BIGINT` | `PK`, `AUTO_INCREMENT` | 自增主键 |
| `conversation_id` | `VARCHAR(36)` | `NOT NULL` | 所属会话 ID |
| `user_id` | `VARCHAR(36)` | `NOT NULL` | 成员 `user.id` |
| `role` | `TINYINT` | `NOT NULL DEFAULT 1` | 成员角色：`1` 普通成员、`2` 管理员 |
| `created_at` | `DATETIME` | `NOT NULL` | 加入时间 |
| `last_read_at` | `DATETIME` | `NULL` | 最后已读时间（用于未读计数） |
| `cleared_at` | `DATETIME` | `NULL` | 单方面清空聊天记录截止时间（Flyway V2 增量兼容） |

索引设计：`UNIQUE KEY uk_conversation_member (conversation_id, user_id)`、`KEY idx_member_user (user_id)`，V3 新增复合索引 `idx_member_user_conversation (user_id, conversation_id)`。

### 3. 消息记录表 `message`

| 字段 | 类型 | 约束 / 默认值 | 说明 |
|---|---|---|---|
| `id` | `VARCHAR(36)` | `PK` | 消息 ID |
| `conversation_id` | `VARCHAR(36)` | `NOT NULL` | 所属会话 ID |
| `sender_id` | `VARCHAR(36)` | `NOT NULL` | 发送者 ID |
| `client_msg_id` | `VARCHAR(64)` | `NULL` | 客户端幂等号（V6 新增） |
| `content_type` | `TINYINT` | `NOT NULL` | 内容类型：`1` 文本、`2` 图片、`3` 文件、`4` 群邀请卡片 |
| `content` | `TEXT` | `NOT NULL` | 文本、COS 链接或邀请卡片 JSON |
| `status` | `TINYINT` | `NOT NULL DEFAULT 1` | 消息状态：`1` 正常、`2` 已撤回（V4/V5 新增） |
| `created_at` | `DATETIME` | `NOT NULL` | 发送时间 |

索引设计：`KEY idx_message_conversation_created (conversation_id, created_at)`、`UNIQUE INDEX uk_message_sender_client_msg (sender_id, client_msg_id)`。

### 4. 入群审批表 `conversation_join_request` & 群邀请记录表 `group_invite`

- **`conversation_join_request`**：记录开启 `join_verify=1` 时的入群待审批工单（`conversation_id`、`user_id`、`status`：`0` 待处理 / `1` 同意 / `2` 拒绝、`handled_by`、`handled_at`），索引为 `KEY idx_join_request_conversation (conversation_id, status)`。
- **`group_invite`**：关联目标群 `group_id`、被邀请人 `invitee_id`、邀请人 `inviter_id`、邀请消息所在会话 `invite_conversation_id`（`VARCHAR(73)`）与卡片 `message_id`，状态覆盖 `0` 待处理、`1` 已加入、`2` 待审批、`3` 已拒绝/失效；索引包含 `idx_invite_conversation`、`idx_group_invitee`、`idx_invitee_status`。
