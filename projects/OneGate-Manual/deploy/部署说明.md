# 部署说明

返回项目主页：[[../README]] ｜ 查看 [[../architecture/架构说明]]

## 环境要求

- JDK 21
- Maven 3.x
- Docker 与 Docker Compose（用于拉起基础中间件）

## 部署步骤

1. 在源码根目录 `D:\workspace\OneGate-Manual` 启动中间件容器（MySQL `3309`、Redis `6382`、RabbitMQ `5673`/`15673`、Nacos `8858`/`9858`），MySQL 首次初始化会自动挂载并执行 `init.sql`。
2. 在 `D:\workspace\OneGate-Manual\backend` 编译打包全部三个模块（`onegate-common`、`onegate-billing-service`、`onegate-gateway-service`）。
3. 按依赖顺序启动后端服务：
   - 先启动 `onegate-billing-service` 主类 `OneGateBillingApplication`（HTTP `:8081`，Dubbo Triple `:20880`）。
   - 再启动 `onegate-gateway-service` 主类 `OneGateGatewayApplication`（HTTP `:8080`，开启虚拟线程）。
   - 服务就绪后访问 `http://127.0.0.1:8080/` 打开实时监控与混沌实验控制台。

## 配置项说明

> 敏感凭据与连接信息严禁在此记录明文，以下仅说明配置项用途与存放位置。

| 配置项 / 环境变量 | 含义 | 存放位置 / 获取方式 |
|------|------|------|
| `MYSQL_HOST` / `MYSQL_PORT` / `MYSQL_USER` / `MYSQL_PASSWORD` / `MYSQL_ROOT_PASSWORD` | MySQL 服务地址、宿主机映射端口及认证账号密码 | 通过环境变量注入；容器编排默认值见 `docker-compose.yml`，计费服务数据源配置位置见 `onegate-billing-service` 的 `application.yml` |
| `REDIS_HOST` / `REDIS_PORT` / `REDIS_PASSWORD` | Redis 服务地址、宿主机映射端口及访问密码 | 通过环境变量注入；默认值见 `docker-compose.yml` 与 `application.yml` |
| `RABBITMQ_HOST` / `RABBITMQ_PORT` / `RABBITMQ_MGMT_PORT` / `RABBITMQ_USER` / `RABBITMQ_PASS` | RabbitMQ AMQP 端口、管理台端口及登录凭据 | 通过环境变量注入；默认值见 `docker-compose.yml` 与 `application.yml` |
| `NACOS_HOST` / `NACOS_PORT` / `NACOS_GRPC_PORT` | Nacos 控制台与 gRPC 端口 | 通过环境变量注入；单机模式配置见 `docker-compose.yml` 与 `application.yml` |
| 租户 API Key 与上游渠道密钥 | 租户调用鉴权密钥与各模型渠道上游访问密钥 | 分别存放在 MySQL `ai_tenant_account`（`api_key` 字段）与 `ai_model_channel`（`masked_key` 字段）表中；初始测试数据脚本位于 `init.sql` |
