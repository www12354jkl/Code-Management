# OneGate-Manual

## 核心功能

### 配额预冻结与防重 %%green%%
- `pre_freeze.lua` 原子脚本 %%green%%
    - `req_id` 幂等拦截
    - 自然分钟 RPM 计数限流
    - 扣减 `avail` 并增加 `frozen`
    - 写入 `FROZEN` 凭证 Hash（24h 过期）
- 预冻结后投递 5 分钟延迟检查消息 %%green%%
- Redis 缓存冷启动按租户预热 %%green%%

### 多退少补结算 %%green%%
- `settle_quota.lua` 原子结算脚本 %%green%%
- Dubbo `settleQuota` RPC 接口 %%green%%
- RabbitMQ 异步落库消费者 `QuotaSettleConsumer` %%green%%

### 异常与超时回滚 %%green%%
- `rollback_quota.lua` 原子回滚脚本 %%green%%
- RabbitMQ 延迟队列 + DLX 死信回滚拓扑 %%green%%
- 测试用 2 秒短延迟队列 %%green%%
- RabbitMQ 超时消费者 `QuotaTimeoutRollbackConsumer` %%green%%

### 运维与黄金对账控制台 %%green%%
- `AdminController`（`/admin`） %%green%%
    - 黄金对账 `/admin/reconcile/{tenantId}`
    - 配额一键重置与 秒级 DLX 演练接口
    - 流水明细查询与渠道权重启停管控

### 网关路由、熔断与控制台 %%green%%
- `ChatCompletionController`（`/v1/chat/completions`） %%green%%
    - Bearer API Key 鉴权与 `tenantAuthCache`（60s）
    - `shortCircuitCache` 欠费 5 秒极速短路保护
    - Dubbo `preFreezeQuota` 原子预冻结（默认 500，范围 50~2000）
    - 成功投递 `SettleMessage`，全失败即时投递回滚
- `ChannelRouter` 与 `SlidingWindowCircuitBreaker` %%green%%
    - 10s 秒级环形桶滑动窗口统计错误率
    - `CLOSED` → `OPEN`（错误率 ≥ 50% 且请求 ≥ 5）→ `HALF_OPEN`（5s 后试探）
    - 上游 429/5xx 秒级 Failover 切换备用渠道
    - `/mock/llm/` 本地进程内低延迟直通
- `MockLlmController`、`HealthController` 与在线控制台 %%green%%
    - `static/index.html`（黄金对账、渠道故障注入沙盘、接口调试与流水表）

## 模块

- `onegate-common`（公共契约层） %%green%%
    - `QuotaBillingRpcService` 接口（6 个 RPC 方法）
    - Redis Key 与 RabbitMQ 拓扑常量
    - 请求 / 响应 / MQ 消息 DTO 与状态枚举
- `onegate-billing-service`（计费核心服务） %%green%%
    - `OneGateBillingApplication`（`:8081` / Dubbo `:20880`）
    - 实体/Mapper、Lua 脚本、Redis/MQ 配置、RPC 实现、MQ 消费者、`AdminController`
    - 单元测试 `QuotaBillingRpcServiceTest`
- `onegate-gateway-service`（网关与控制台服务） %%green%%
    - `OneGateGatewayApplication`（`:8080` / 虚拟线程）
    - `ChatCompletionController`、`ChannelRouter`、`SlidingWindowCircuitBreaker`、`CaffeineConfig`
    - `MockLlmController`、`HealthController`、`static/index.html`
    - 单元测试 `SlidingWindowCircuitBreakerTest`

## 技术选型

- Java 21（虚拟线程）+ Spring Boot 3.3.5
- Spring Cloud 2023.0.3 + Alibaba 2023.0.3.2
- Apache Dubbo 3.3.6（Triple）+ Nacos 2.3.2
- Redis 7.2（Lua）+ Caffeine 3.1.8
- RabbitMQ 3.13（TTL + DLX 死信）
- MySQL 8.0.36 + MyBatis-Plus 3.5.9
- Tailwind CSS（控制台前端）
