# OneGate-Manual

## 核心功能

### 配额预冻结与防重 %%green%%
- `pre_freeze.lua` 原子脚本 %%green%%
    - `req_id` 幂等拦截
    - 自然分钟 RPM 计数限流
    - 扣减 `avail` 并增加 `frozen`
    - 写入 `FROZEN` 凭证 Hash（24h 过期）
- 预冻结后投递 5 分钟延迟检查消息 %%green%%
- Redis 缓存冷启动按租户预热 %%green%%

### 多退少补结算 %%green%%
- `settle_quota.lua` 原子结算脚本 %%green%%
- Dubbo `settleQuota` RPC 接口 %%green%%
- RabbitMQ 异步落库消费者 `QuotaSettleConsumer` %%green%%

### 异常与超时回滚 %%green%%
- `rollback_quota.lua` 原子回滚脚本 %%green%%
- RabbitMQ 延迟队列 + DLX 死信回滚拓扑 %%green%%
- 测试用 2 秒短延迟队列 %%green%%
- RabbitMQ 超时消费者 `QuotaTimeoutRollbackConsumer` %%green%%

### 运维与黄金对账控制台 %%green%%
- `AdminController`（`/admin`） %%green%%
    - 黄金对账 `/admin/reconcile/{tenantId}`
    - 配额一键重置与 秒级 DLX 演练接口
    - 流水明细查询与渠道权重启停管控

### 网关路由与鉴权（待创建）
- API Key 鉴权与 Caffeine 本地缓存
- 欠费 5 秒短路保护
- 模型渠道平滑加权负载均衡与熔断
- 上游 LLM 调用与结算消息投递

## 模块

- `onegate-common`（公共契约层） %%green%%
    - `QuotaBillingRpcService` 接口（6 个 RPC 方法）
    - Redis Key 与 RabbitMQ 拓扑常量
    - 请求 / 响应 / MQ 消息 DTO 与状态枚举
- `onegate-billing-service`（计费核心服务）
    - 已完成：实体/Mapper、Lua 脚本、Redis/MQ 配置、RPC 实现、MQ 消费者、`AdminController` %%green%%
    - 待补充：Spring Boot 启动类、单元测试
- `onegate-gateway`（网关服务，待创建）

## 技术选型

- Java 21（虚拟线程）+ Spring Boot 3.3.5
- Spring Cloud 2023.0.3 + Alibaba 2023.0.3.2
- Apache Dubbo 3.3.6（Triple）+ Nacos 2.3.2
- Redis 7.2（Lua）+ Caffeine 3.1.8
- RabbitMQ 3.13（TTL + DLX 死信）
- MySQL 8.0.36 + MyBatis-Plus 3.5.9
